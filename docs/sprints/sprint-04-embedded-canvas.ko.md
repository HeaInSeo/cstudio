# Sprint 04 - 임베드된 DagEdit 캔버스

## 목표

`cstudio`의 중앙 문서 호스트 안에 실제 `DagEdit` 편집 표면을 배치한다.

## 범위

- 문서 탭이 텍스트 요약과 실제 Avalonia 콘텐츠를 모두 담을 수 있도록 확장
- 어댑터 계층에 `DagEditDocumentView` 추가
- 어댑터 샘플 그래프를 임베드된 편집기에 주입
- 중앙 텍스트 패널을 실제 캔버스로 바꾸면서도 전체 셸 형태는 `GPU-Reshape Studio` 참고 구조를 유지

## 완료 기준

- 솔루션이 정상 빌드된다
- 첫 번째 문서 탭이 실제 `DagEdit` 편집기 컨트롤을 호스팅한다
- 나머지 진단 문서 탭은 기존 텍스트 기반으로 계속 동작한다
- 로드맵과 스크린샷 문서가 한글/영문으로 갱신된다

## 상태

완료.
