# Sprint 05 - Interactive Shell Sync

## 목표

임베드된 `DagEdit` 캔버스의 라이브 상태를 주변 `cstudio` 셸 패널에 다시 반영한다.

## 범위

- 임베드 캔버스 상태 변경 시 UI에 알릴 수 있는 셸 상태 서비스 추가
- 임베드된 뷰포트 이동을 속성, 상태영역, 워크스페이스 크롬으로 전달
- 임베드된 선택 변경을 셸 라벨과 진단 정보로 전달
- 향후 `DagEdit` 통합을 위해 셸 계약 구조는 재사용 가능하게 유지

## UI 변경점

- 워크스페이스 라벨에 현재 임베드 선택 요약이 포함됨
- 좌측 상태 영역에 라이브 뷰포트 좌표와 선택 종류가 표시됨
- 우측 상태 배지에 라이브 스케일과 선택 상태가 표시됨
- 속성 패널에 선택 종류, 선택 라벨, 라이브 뷰포트 값이 추가됨
- 로그 패널에 최근 임베드 캔버스 동기화 이벤트가 반영됨

## 완료 기준

- 솔루션이 정상 빌드된다
- 임베드된 캔버스의 뷰포트 또는 선택이 바뀌면 셸 패널이 함께 반응한다
- 스프린트 문서와 스크린샷 문서가 한글/영문으로 UI 영향을 명확히 보여준다
