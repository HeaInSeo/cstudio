# Sprint 00 - Foundation

영문 버전:

- [sprint-00-foundation.md](sprint-00-foundation.md)

## 목표

`cstudio` 저장소를 세우고 `GPU-Reshape Studio`를 참고한 첫 실행 가능한 셸을 만든다.

## 범위

- 저장소 초기화
- 빌드 및 스타일 설정
- Avalonia 앱 스캐폴딩
- 목 데이터 기반 셸 레이아웃
- 첫 스프린트 스크린샷 문서 추가

## 완료 기준

- 솔루션이 빌드된다
- 앱이 실행된다
- 메인 셸 레이아웃이 보인다
- 스크린샷 문서가 커밋된다

## 상태

완료.
