# CStudio 로드맵

## 목적

이 문서는 `cstudio`의 전체 진행 계획을 관리한다. `cstudio`는 나중에 `DagEdit`에 UI를 옮길 때 비용을 줄이기 위한 전단계 셸 프로젝트다.

이 문서는 매 스프린트 종료 시점마다 반드시 갱신한다.

영문 버전:

- [ROADMAP.en.md](ROADMAP.en.md)

## 스프린트 종료 시 업데이트 규칙

각 스프린트가 끝날 때마다 다음을 수행한다.

1. 이 문서의 상태 표를 갱신한다
2. `docs/sprints/` 아래 스프린트 문서를 추가 또는 갱신한다
3. `docs/screenshots/` 아래 스크린샷 문서를 추가 또는 갱신한다
4. 결과를 GitHub에 푸시한다

## 상시 UI 업데이트 규칙

UI가 주요하게 바뀌거나 눈에 띄는 변경이 생기면 항상 다음을 수행한다.

1. 해당 스크린샷 문서를 갱신한다
2. GitHub에서 바로 볼 수 있는 미리보기 이미지 또는 스크린샷 자산을 갱신한다
3. 갱신된 UI 상태를 GitHub에 푸시한다

이 규칙은 별도 변경 요청이 있기 전까지 계속 유지한다.
