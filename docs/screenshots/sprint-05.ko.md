# Sprint 05 스크린샷 노트

## 개요

Sprint 05에서는 주변 셸이 임베드된 `DagEdit` 캔버스에 반응하도록 만들었다.

중앙 편집기는 Sprint 04와 동일하게 임베드되어 있지만, 이제 그 주변의 UI 크롬이 정적인 값이 아니라 라이브 뷰포트와 선택 상태를 반영한다.

## 미리보기

![Sprint 05 shell preview](assets/sprint-05-shell-preview.svg)

## 이번 스프린트의 시각적 신호

- 워크스페이스 라벨에 현재 선택 요약이 포함됨
- 좌측 상태 영역에 `Selection` 과 라이브 `Viewport` 가 표시됨
- 우측 배지에 라이브 `Scale` 과 선택 종류가 표시됨
- 속성 패널에 `Selection Kind`, `Selection Label`, 라이브 뷰포트 값이 노출됨
- 로그 패널에 임베드 캔버스의 최근 동기화 및 선택 이벤트가 표시됨

## UI 참고 사항

- 이번 스프린트는 내부 계약만이 아니라, 실제로 보이는 셸 UI를 변경한 스프린트다
- 목표는 셸이 분리된 호스트처럼 보이지 않고, 임베드된 편집기와 연결된 화면처럼 느껴지게 만드는 것이다
